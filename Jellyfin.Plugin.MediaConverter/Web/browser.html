Automatic Conversion Rules

Each rule scans the whole library and queues any movie/episode not already in its target codec (matching a path filter, if set). Rules run via the "Apply Media Converter rules" scheduled task - configure its schedule from Jellyfin's own Scheduled Tasks page - or trigger a scan immediately below. An item already queued/converted once is never re-queued by a rule.
